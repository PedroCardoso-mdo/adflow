## Step 3 — the lesson to apply proactively (don't relearn it)

The γ-Re̅θt branch's first physics reference was a hand-written "distilled"
summary of the paper, not the paper itself. Over two audit passes it
accumulated **5 transcription errors** (wrong formula branch, missing a
term, garbled blend-function algebra, and a whole algorithm misread as a
single scalar where the paper actually specified two independent
per-variable loops) — the code was correct every time, only the distilled
doc was wrong, and future tasks nearly got misled by it before each error
was caught by cross-checking the real paper.

**Apply this now, not after 5 errors:** never create a "distilled" or
"summary" physics doc as the working reference. Point `CLAUDE.md` rule 9 and
every routing-table row directly at the full paper text
(`docs/<PAPER_BASE>/<paper>.md`). If you want a quick-reference table of
paper-symbol ↔ code-flag mappings, that's fine (that's what `architecture.md`
Part 2 is for) — the failure mode was re-deriving physics *content* in prose
and letting that prose drift from the source, not maintaining a lookup table.

### 5a. `tests/reg_tests/reg_bcm.py`

```python
"""Shared configuration and helpers for the SA-BCM <full name> derivative
regression tests.

This module plays the role reg_default_options.py / reg_aeroproblems.py /
reg_test_utils.py play for the SA and Euler cases, plus SA-BCM-specific
helpers <that isolate the new state variables and coupling blocks, if any —
see docs/audits/ for the wiring investigation this mirrors>.

<If new state vars>: State-vector layout (verify against
NKSolvers.F90:getStates or equivalent): the flattened state/residual
vectors are variable-fastest, w(i,j,k,1:nw). For SA-BCM nw = <N> with
<itu1/itu2/...> = <Fortran indices> (Fortran, 1-based) = <var names>.

The grid/restart/FFD files below are placeholders until a converged SA-BCM
case is generated (generate_bcm_restart.py).
"""

import os
from collections import OrderedDict

import numpy
from baseclasses import AeroProblem
from baseclasses.testing import getTol

baseDir = os.path.dirname(os.path.abspath(__file__))

# --------------------------------------------------------------------------
# Case inputs
# --------------------------------------------------------------------------
bcmGridFile = os.path.join(baseDir, "../../input_files/<grid>.cgns")
bcmRestartFile = os.path.join(baseDir, "../../input_files/<bcm restart>.cgns")
bcmFFDFile = os.path.join(baseDir, "../../input_files/<ffd>.fmt")

ap_bcm_case = AeroProblem(
    name="<case name>",
    alpha=<...>, beta=0.0, mach=<...>, P=<...>, T=<...>, R=287.87,
    areaRef=<...>, chordRef=<...>, xRef=0.0, yRef=0.0, zRef=0.0,
    evalFuncs=["cl", "cd", "cmz", "drag"],
)

# Aero DVs that exercise SA-BCM's modified/new terms specifically —
# identify these from Step 0 (which freestream quantities feed the new
# source terms / correlations, analogous to mach/P/T -> uInf/muInf for the
# vorticity limiter in the γ-Re̅θt precedent)
bcmAeroDVs = ["alpha", "mach", <...>]

# Solver options: list EVERY SA-BCM-relevant option explicitly, each with
# an inline comment explaining what it does and why that value — not just
# the bare value. Base this on what Step 0 found in pyADflow.py.
bcmBaseOptions = {
    "gridfile": bcmGridFile,
    "restartfile": bcmRestartFile,
    "equationtype": "RANS",
    "turbulencemodel": "<SA-BCM enum string>",
    # ... every SA-BCM option, commented ...
    "frozenturbulence": False,  # adjoint must include the new/modified terms
}


# --------------------------------------------------------------------------
# [IF NEW STATE VARS] State-vector block helpers
# --------------------------------------------------------------------------
def getStateBlocks(CFDSolver):
    """Return (nw, blocks): block name -> 0-based variable offsets."""
    nw = int(CFDSolver.adflow.flowvarrefstate.nw)
    nt1 = int(CFDSolver.adflow.flowvarrefstate.nt1)
    nt2 = int(CFDSolver.adflow.flowvarrefstate.nt2)

    if nw != <N> or (nt2 - nt1) != <N-1>:
        raise ValueError(
            "SA-BCM tests expect the <N>-state layout; got nw=%d, nt1=%d, nt2=%d"
            % (nw, nt1, nt2)
        )

    blocks = OrderedDict()
    blocks["meanflow"] = list(range(0, nt1 - 1))
    blocks["nuTilde"] = [nt1 - 1]
    blocks["<newvar1>"] = [nt1]
    # ... one entry per new state variable ...
    return nw, blocks


def maskStateVector(vec, nw, offsets):
    masked = numpy.zeros_like(vec)
    for off in offsets:
        masked[off::nw] = vec[off::nw]
    return masked


def assert_coupling_blocks_allclose(handler, CFDSolver, seed=314, mode=None, h=None, **kwargs):
    """Column-by-column forward products dR/dw * e[block], result norms
    split by residual row block — covers every SA<->new-equation cross term.
    """
    rtol, atol = getTol(**kwargs)
    nw, blocks = getStateBlocks(CFDSolver)
    wDotFull = CFDSolver.getStatePerturbation(seed)
    extraArgs = {"mode": mode, "h": h} if mode is not None else {}

    for colName, colOffsets in blocks.items():
        wDot = maskStateVector(wDotFull, nw, colOffsets)
        resDot = CFDSolver.computeJacobianVectorProductFwd(wDot=wDot, residualDeriv=True, **extraArgs)
        for rowName, rowOffsets in blocks.items():
            rowDot = maskStateVector(resDot, nw, rowOffsets)
            key = "||dR[%s]/dw[%s] * eDot||" % (rowName, colName)
            handler.root_print(key)
            handler.par_add_norm(key, rowDot, rtol=rtol, atol=atol)


def assert_bcm_xdvdot_allclose(handler, CFDSolver, ap, seed=1.0, mode=None, h=None, **kwargs):
    """Forward products dR/d(aeroDV), row-block-split — targets the
    freestream-condition path into the new/modified terms."""
    rtol, atol = getTol(**kwargs)
    nw, blocks = getStateBlocks(CFDSolver)
    extraArgs = {"mode": mode, "h": h} if mode is not None else {}

    for aeroDV in ap.DVs.values():
        key = aeroDV.key
        resDot = CFDSolver.computeJacobianVectorProductFwd(xDvDot={key: seed}, residualDeriv=True, **extraArgs)
        for rowName, rowOffsets in blocks.items():
            rowDot = maskStateVector(resDot, nw, rowOffsets)
            name = "||dR[%s]/d%s||" % (rowName, key)
            handler.root_print(name)
            handler.par_add_norm(name, rowDot, rtol=rtol, atol=atol)


def assert_bwdfast_blocks_allclose(CFDSolver, seed=314, atol=1e-16):
    """Row-block-seeded _b vs _fast_b consistency — isolates each
    transposed coupling column; a failure isolated to the new-variable
    seeds signals autoEditReverseFast.py push/pop stripping, not a model bug."""
    nw, blocks = getStateBlocks(CFDSolver)
    dwBarFull = CFDSolver.getStatePerturbation(seed)
    for rowName, rowOffsets in blocks.items():
        dwBar = maskStateVector(dwBarFull, nw, rowOffsets)
        wBar = CFDSolver.computeJacobianVectorProductBwd(resBar=dwBar, wDeriv=True)
        wBarFast = CFDSolver.computeJacobianVectorProductBwdFast(resBar=dwBar)
        numpy.testing.assert_allclose(
            wBar, wBarFast, atol=atol, err_msg="BWD vs BWDFast, resBar seeded on %s rows" % rowName
        )


def assert_coupling_dot_products_allclose(handler, CFDSolver, seed=314, **kwargs):
    """Blockwise transpose tests isolating each off-diagonal Jacobian block
    in both AD modes simultaneously. Proves consistency, not correctness —
    correctness comes from the CS classes."""
    rtol, atol = getTol(**kwargs)
    nw, blocks = getStateBlocks(CFDSolver)
    wDotFull = CFDSolver.getStatePerturbation(seed)
    dwBarFull = CFDSolver.getStatePerturbation(seed + 1)

    pairs = [
        # (column block seeded in wDot, row block seeded in dwBar) —
        # one pair per off-diagonal coupling block Step 0 identified
    ]
    for colName, rowName in pairs:
        wDot = maskStateVector(wDotFull, nw, blocks[colName])
        dwBar = maskStateVector(dwBarFull, nw, blocks[rowName])
        dwDot = CFDSolver.computeJacobianVectorProductFwd(wDot=wDot, residualDeriv=True)
        wBar = CFDSolver.computeJacobianVectorProductBwd(resBar=dwBar, wDeriv=True)
        key = "Dot product test for w[%s] -> R[%s]" % (colName, rowName)
        handler.root_print(key)
        handler.par_add_sum(key, numpy.sum(dwDot * dwBar), rtol=rtol, atol=atol)
        handler.par_add_sum(key, numpy.sum(wDot * wBar), rtol=rtol, atol=atol, compare=True)
```

### 5b. `tests/reg_tests/generate_bcm_restart.py`

```python
#!/usr/bin/env python
"""Generate the SA-BCM restart CGNS for the derivative regression tests
(test_*_bcm.py).

Takes <grid>, converges it with SA-BCM at a chosen Mach, writes a
grid+solution CGNS used as `restartfile`. Refuses silently-wrong output:
warns loudly if the solve didn't converge and tells you not to use that
file as a test restart.

Run on the REAL (not complex) build:
    python generate_bcm_restart.py --mach <M> --<bcm-specific-param> <v>
then update reg_bcm.py to match exactly the converged conditions.
"""

import argparse
import copy
import os

from adflow import ADFLOW
from baseclasses import AeroProblem

from reg_default_options import adflowDefOpts
from reg_bcm import bcmBaseOptions

baseDir = os.path.dirname(os.path.abspath(__file__))


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--gridFile", default=os.path.join(baseDir, "../../input_files/<grid>.cgns"))
    parser.add_argument("--output", default=os.path.join(baseDir, "../../input_files/<bcm_restart>.cgns"))
    parser.add_argument("--mach", type=float, default=<...>)
    parser.add_argument("--alpha", type=float, default=<...>)
    parser.add_argument("--l2", type=float, default=1e-14)
    parser.add_argument("--ncycles", type=int, default=40000)
    parser.add_argument("--restartfile", default=None,
        help="restart from this CGNS instead of a cold start (continue converging)")
    parser.add_argument("--nk", action="store_true",
        help="switch to the NK solver path once ANK has it in the basin of attraction")
    args = parser.parse_args()

    options = copy.copy(adflowDefOpts)
    options.update(copy.deepcopy(bcmBaseOptions))
    options["gridfile"] = args.gridFile
    if args.restartfile is not None:
        options["restartfile"] = args.restartfile
    else:
        options.pop("restartfile", None)
    options["l2convergence"] = args.l2
    options["ncycles"] = args.ncycles
    options["outputdirectory"] = os.path.dirname(os.path.abspath(args.output))
    options["solutionprecision"] = "double"  # tests linearize about exactly this state
    options["writevolumesolution"] = False
    options["writesurfacesolution"] = True
    options["surfacevariables"] = ["cp", "vx", "vy", "vz", "mach", "cf", "cfx", "cfy", "cfz"]
    if args.nk:
        options["useanksolver"] = False
        options["usenksolver"] = True
```

```markdown
## Verification ladder / how to read failures

1. **FD class fails, CS passes** → FD step/kink noise, not an AD bug.
2. **CS block/row key fails** → that specific Jacobian term is wrong in the
   forward code.
3. **`_fast_b` block-row test fails on new-variable seeds only** → suspect
   `autoEditReverseFast.py` push/pop stripping before suspecting the model.
4. **Dot products fail** → fwd and rev disagree with each other
   (bookkeeping); they can also both be wrong identically and still pass —
   hence CS is required, not optional.
5. **cmplx_test on a specific freestream/geometric DV fails** → points at
   the exact term that DV feeds (freestream-condition BC path, correlation
   chain, etc.) — cross-reference `docs/architecture.md`.

**Never fix a failing comparison by inflating its tolerance.** This is the
single most important rule carried over from a prior turbulence-model
verification effort where tolerance-inflation masked a real bug that then
shipped unverified.
```
