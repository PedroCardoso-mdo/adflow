# Developer notes

Where the code is, the conventions that are easy to get wrong, how the derivative code is generated, and
how this fork differs from upstream ADflow. Where this page and the code disagree, the code is right.

## 1. Code map

State vector: `w(:,:,:,1:5)` = ρ, u, v, w, ρE; `itu1` = ν̃; `itu2` = γ (GR, SA-γ); `itu3` = R̅eθt (GR).
Model identifiers: `spalartallmarasnoft2gammaretheta` and `spalartallmarasnoft2gamma` in
`src/modules/constants.F90`. SA-BCM has no identifier of its own (it is plain SA with `useSABCM`).
Every path that is not specific to R̅eθt accepts both identifiers.

## 2. Non-dimensionalisation

ADflow uses a pressure–density non-dimensionalisation, not a velocity-based one. The source of truth is
`referenceState` in `src/initFlow/initializeFlow.F90` and the comments in `src/modules/flowVarRefState.F90`.

| Quantity                                 | Value in the code                          | Consequence                                                          |
| ---------------------------------------- | ------------------------------------------ | -------------------------------------------------------------------- |
| Reference pressure, density, temperature | free-stream values                         | p∞ = 1, ρ∞ = 1                                                       |
| Reference length                         | 1 m (coordinates are converted to metres)  | never appears explicitly; lengths are physical lengths in metres     |
| Velocity scale                           | √(p_ref/ρ_ref)                             | **free-stream speed is M·√γ_gas, not 1**                             |
| Viscosity scale                          | √(p_ref·ρ_ref)                             | ρ_ref·u_ref/μ_ref = 1                                                |
| Time scale                               | √(ρ_ref/p_ref)                             | `timeRef`                                                            |
| `rlv`, `rev`                             | μ/μ∞ and μ_t/μ∞ (ratios)                   | not multiplied by 1/Re                                               |
| Reynolds number                          | enters only through `muInf` = μ∞,dim/μ_ref | u∞/ν∞ in code units is the physical unit Reynolds number (per metre) |

### Porting an equation from a paper

Piotrowski and Zingg non-dimensionalise with the free-stream sound speed and a reference length, so their
equations carry explicit Re or 1/Re factors (time scale, θ, Re_S, λ_θ, Re_scf). In ADflow those factors
are absorbed by the non-dimensional viscosity.

| Rule                                                                                       | Example                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Keep velocities in code units and viscosities as stored; **drop the paper's Re and 1/Re**  | Time scale of the R̅eθt source: paper t = 500·μ/(ρU²)·(1/Re); code `timeScale = 500·nu/velMag2`                                                                                                                                                                                                                  |
| ν-based groups then evaluate to physical values                                            | θ = R̅eθt·ν/U is the momentum thickness in metres; Re_S, Re_v, R̅eθt are physical Reynolds numbers, as the correlations expect                                                                                                                                                                                    |
| Lengths given as inputs are in mesh units                                                  | `transitionRoughnessHeight` 3.3e-6 = 3.3 µm on a metre-scaled mesh; rescale it with the mesh                                                                                                                                                                                                                    |
| **Exception: the vorticity limiter**                                                       | In M·√(M·Re)/20 the √Re is a physical calibration scale (wall vorticity of a boundary layer ∝ √(ρU³/(μ·l))), tied by the paper to the root chord. Dropping it would silently set l = 1 m. The code keeps the length: Ω_cap = U·√(U/(ν∞·l))/20 with l = `transitionRefLength` (default: AeroProblem `chordRef`). |
| A threshold built from free-stream quantities makes the residual depend on the free stream | `uInf` and `muInf` must be declared as active inputs of the source routines in the Tapenade heads, otherwise ∂R/∂Mach-type derivatives miss the limiter in the cells where it acts (∂R/∂w is unaffected).                                                                                                       |

The crossflow term follows the same rules: h/θ is a ratio of two physical lengths, H_cf is dimensionless,
Re_scf is a physical Reynolds number, D_scf has the units of the R̅eθt production, and no Re factor appears.
For SA-BCM the vorticity is in code units and ν̃/ν is a ratio, so no Re factor appears either.

## 3. Derivative code

### What is differentiated

| Model      | Routines differentiated in forward and reverse mode                               | State-only reverse ("fast")                   |
| ---------- | --------------------------------------------------------------------------------- | --------------------------------------------- |
| SA, SA-BCM | `sa%saSource`, `sa%saViscous`, `sa%saResScale`                                    | same routines, inputs `w`, `rlv`              |
| GR         | `saGammaRetheta%Source` (inputs include `uInf`, `muInf`), `%Viscous`, `%ResScale` | `Source(w, rlv)`, `Viscous`, `ResScale`       |
| SA-γ       | `saGamma%sgSource` (inputs include `uInf`, `muInf`), `%sgViscous`, `%sgResScale`  | `sgSource(w, rlv)`, `sgViscous`, `sgResScale` |
| all        | turbulence advection, eddy viscosity, turbulence boundary conditions              | same                                          |

SA-BCM has no routine of its own: its intermittency is inside `saSource`. The correlations and
`smoothMinMax` are differentiated through the source routines.

Not differentiated, so changes confined to them need no regeneration: everything behind
`#ifndef USE_TAPENADE` (the implicit left-hand side of the DADI solve, the block-tridiagonal solvers, the
non-negativity clips of the diagonal), `evalSrcJacBlock*` and `computeSrcLambda*` (preconditioner and
time-step restriction only), the diagnostics array.

A new model needs a case in **all five** sweeps of `masterRoutines.F90` and its three routine heads in
`Makefile_tapenade`; a missing one drops terms from the adjoint without an error.

### Regenerating

```bash
cd src/adjoint
make -f Makefile_tapenade ad_forward ad_reverse ad_reverse_fast   # needs TAPENADE_HOME; run in the foreground
cd ../..
make                      # real build; build the complex library as well before any complex-step check
rm -rf build && pip install . --no-deps
```

The generated files in this repository were produced with Tapenade 3.16. Regenerate after any change to a
differentiated routine or to a module variable it reads, then run the ladder of
[verification.md](verification.md) (retrain the references first).

### Known traps

| Trap                                                            | Symptom                                                                                                                                                                                             | What to do                                                                                                                           |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Identifier ending in `_c`                                       | Collides with names Tapenade generates                                                                                                                                                              | Do not use such names in differentiated code                                                                                         |
| In-place clamp of an active variable, `x = smoothMinMax(x, …)`  | The fast reverse code is wrong (once with the wrong sign on the R̅eθt rows) while forward, reverse and complex step agree: the post-processing removes the push/pop that saves the overwritten value | Use distinct targets (`raw` → `clamped` → `local`)                                                                                   |
| Module variable passed directly to a differentiated helper      | Wrong or missing derivative code for the argument                                                                                                                                                   | Copy the module variable to a local first, pass the local                                                                            |
| Source line longer than 132 columns                             | Tapenade fails to parse the unit, **the make target still returns 0**, and the old generated file stays in place                                                                                    | After every regeneration search the Tapenade log for "not found" and check the modification times of the `_d`, `_b`, `_fast_b` files |
| Routine with branches and a restricted `use constants, only: …` | Generated code misses symbols                                                                                                                                                                       | Import `constants` without an `only` list                                                                                            |
| Bare real literal passed to `smoothMinMax`                      | Kind mismatch in the complex build                                                                                                                                                                  | Pass named parameters from `paramTurb`                                                                                               |
| `USE_COMPLEX` branch in residual code                           | Real and complex builds compute different residuals                                                                                                                                                 | Keep the residual kind-generic; real-part casts only in solver step limiters                                                         |
| Active input missing from a routine head                        | Complex-step partials fail on the transition rows of ∂R/∂(Mach, P, T)                                                                                                                               | Add the input (e.g. `uInf`, `muInf`) to the head                                                                                     |
| Option not declared in `adflow.pyf`                             | The option has no effect and no error is raised                                                                                                                                                     | Declare it in the module block; read it back from Fortran memory to confirm                                                          |
| Hand edit of generated code                                     | Lost at the next regeneration, and the derivative no longer matches the source                                                                                                                      | Change the source or the `autoEdit` scripts and regenerate                                                                           |

## 4. Rotating frames

The model is validated only on inertial-frame cases. On a rotating mesh the GR transition terms are
evaluated in the relative frame, where the blade boundary layer is steady and the correlations are defined.
Every change reduces exactly to the inertial formula when the rotation rate is zero.

| Term                                           | In a rotating frame                                                                      |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Stored velocity                                | absolute (the rotating no-slip wall sets Ω×r)                                            |
| Vorticity used by the model                    | curl of the absolute velocity − 2Ω = relative vorticity (same convention as upstream SA) |
| Vorticity-limiter speed                        | √(U∞² + (Ω×r)²), the local section speed, instead of U∞ (which vanishes in hover)        |
| θ, time scale, δ, streamwise direction for λ_θ | relative velocity V − Ω×r, with Ω×r evaluated at the cell centre                         |
| Helicity parameter H_cf                        | relative velocity and relative vorticity (helicity is not frame invariant)               |
| Strain rate, velocity-gradient stencils        | unchanged (frame invariant; in dU/ds the antisymmetric rotation part cancels)            |

The correction is applied in every copy of the GR source logic (residual, DADI Jacobian,
`evalSrcJacBlock`). SA-γ computes its kinematics in the relative frame in the same way.
`warnRotatingTransition` reports once which form is active: a rotation rate defined on the mesh sections is
corrected for; one set only through the Python `setRotationRate` call is not (the same limitation as
upstream SA).

Status: the zero-rotation case is bit-identical and the derivative suites passed with the correction in
place, but **no rotating case has been run**. Near the axis in pure hover the limiter speed tends to zero.

## 5. Solver internals worth knowing

Items already covered in [recipes.md](recipes.md) (ladders, line-search tolerances, CFL ceiling, memory)
are not repeated.

| Topic                                          | Finding                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Which phase is the paper's "inexact Newton"    | The phase (T + A₂)·ΔQ = −R of Piotrowski's solver is ADflow's second-order ANK (CSANK), not NK. NK is its limit with no time term. Letting CSANK finish with `useNKSolver=False` is the paper's algorithm, not a workaround.                                                                                                                                                                                                                                                                                        |
| Source-term time-step restriction              | λ_source is the largest positive eigenvalue of the source Jacobian, which is block triangular, so the eigenvalue is exact. DADI: added to the diagonal (`qq += λ/limit`), never released. Krylov paths: `max(1/Δt, λ/limit)` on the turbulence diagonal, released after `srcDtDeactivateIters` steps without backtracking, re-armed on a backtrack. Only the left-hand side is touched; the converged solution is the same. The limit is 0.9; the thesis and the solver paper use 0.8 (not tested as a difference). |
| Release on a flat residual                     | Once released, the restriction is not re-armed by a residual that stays flat. Raising `srcDtDeactivateIters` to 100000 on a stalled case moved the stalled residual slightly and did not remove the stall.                                                                                                                                                                                                                                                                                                          |
| Per-node damping (P&Z Algorithm 2)             | DADI: γ and R̅eθt are damped independently, each with its own back-off loop θ^m (`transitionDampTheta`, capped by `transitionDampMaxIter`); ν̃ is only kept non-negative. A hard clip to the bounds follows only if a loop is exhausted. NK: `applyNKAlgorithm2Damping`. Coupled ANK: `applyANKAlgorithm2Damping`, active exactly when `ANKTransitionGlobalLambda=False`.                                                                                                                                             |
| Physicality check in segregated turbulence ANK | γ: absolute bounds [1e-10, 2]; the full step is taken unless it violates them, with a floor of 0.05 on the step factor. A relative check would collapse the step in laminar regions. ν̃ and R̅eθt: relative tolerances (`ANKPhysicalLSTolTurb`; 0.99 for R̅eθt). The two numbers 0.05 and 0.99 are constants.                                                                                                                                                                                                          |
| What limits the coupled step                   | Measured on the swept wing over about 7200 coupled iterations: γ set the global step in 7143 of them, ν̃ in 53, density in 3. A few cells at the transition front throttle the whole field; this is what `ANKTransitionGlobalLambda=False` removes.                                                                                                                                                                                                                                                                  |
| CFL floor                                      | The ANK CFL floor is itself ramped with convergence, so deep in the convergence the CFL cutback has no room to act; `ANKCFLMinCap` puts an absolute ceiling on the floor. After a deep restart the CFL re-ramps from `ANKCFLMin·(R₀/R)^0.5`.                                                                                                                                                                                                                                                                        |
| Unsteady line search                           | With factor 0.7 and 12 backtracks the smallest step is 0.7¹² = 0.0138, above the 0.01 rejection threshold, so an exhausted search is never treated as a failed step. `ANKUnsteadyLSFactor`, `ANKUnsteadyLSMaxIter`, `ANKRejectOnLSExhausted` expose this.                                                                                                                                                                                                                                                           |
| NK has no density / energy physicality check   | ANK has one; NK relies on NaN detection and the γ / R̅eθt damping. This is why the relaxed NK line search (`NKLSRelax`: Armijo constant 1e-3, turbulence pre-limit 3.0) cannot be relaxed further: 1e-4 or a factor 5.0 let through steps that diverge.                                                                                                                                                                                                                                                              |
| Column scaling                                 | The state spans about 13 orders of magnitude. The Krylov systems are column-scaled with the inverse of `turbResScale`; switching the scaling off inside the NK phase diverged at two different residual levels, so it is needed for the whole phase, not only at entry.                                                                                                                                                                                                                                             |
| Matrix-free differencing                       | PETSc chooses one differencing step for the whole vector, assuming the residual is exact to machine precision. `MFFDFunctionError`, `MFFDType` and `ANKColScaleUnit` expose the step choice and a unit-RMS scaling. On the swept wing they changed nothing, because the binding constraint was the CFL ceiling.                                                                                                                                                                                                     |
| Row scale of ν̃                                 | 1e4 rather than the paper's 1e3: the ν̃ residual is ADflow's SA residual and keeps its scaling; γ and R̅eθt use about 1 / state magnitude.                                                                                                                                                                                                                                                                                                                                                                            |
| `ANKNSubiterTurb` and `nSubiterTurb`           | `ANKNSubiterTurb` acts only with the turbulence KSP; with `ANKUseTurbDADI=True` only `nSubiterTurb` reaches the DADI solve.                                                                                                                                                                                                                                                                                                                                                                                         |
| Holding a phase too long (3D wing)             | Coupled ANK past about 1e-7 or CSANK past about 3.5e-8: a small adjustment of the front kicks the residual and the phase oscillates. Hand over before.                                                                                                                                                                                                                                                                                                                                                              |
| Early coupling                                 | On the plain 3D wing coupling at 1e-2 or 1e-4 stagnated and 1e-5 was best; the crossflow cases and the 2D polars are validated with coupling at 1e-2 or 1e-3. The level is case dependent; use the recipe of the nearest case.                                                                                                                                                                                                                                                                                      |
| Deep NK                                        | Below about 5e-9 relative the NK linear residual sits at 0.8–0.99 with the Krylov space exhausted. Tried without effect: fixed linear tolerance 0.3 without Eisenstat–Walker, ILU fill 3 (worse than 2), Jacobian lag 5. Not tried: more inner / outer preconditioner iterations.                                                                                                                                                                                                                                   |
| Stopping a run                                 | SIGUSR2 ends the current solve and writes the solution. A script with several solves continues with the next one.                                                                                                                                                                                                                                                                                                                                                                                                   |
| Blockette path                                 | Forced off for GR and SA-γ (performance cost only). SA-BCM uses it, as plain SA does.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Lesson: monotonic error trend                  | On the swept wing the Reynolds length was first set to √2 instead of the chord normal to the leading edge; every run was a factor √2 low in Reynolds number and the error grew monotonically with Re, which looked like a weak crossflow term. A monotonic trend points at a wrong parameter before a wrong model.                                                                                                                                                                                                  |

## 7. Build notes

| Topic               | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Build               | As upstream ADflow: copy a file from `config/defaults/` to `config/config.mk`, `make`, `pip install .`. Complex library: the upstream complex makefile against a complex PETSc architecture.                                                                                                                                                                                                                                                                                                                       |
| **No OpenMP flags** | Do not add `-fopenmp` to the compiler or linker flags. With it, the loop of the blockette residual privatises its indices and the wall shear stress stored for the force integration goes stale: the residual and the state are right, the viscous drag is wrong. Seen as a difference of 1.1e-3 (SA) and 1.6e-2 (SA-BCM) in cd on the tutorial wing between a build with the flag and one without. Run with one MPI rank per core and `OMP_NUM_THREADS=1`. The files in `config/defaults/` do not carry the flag. |
| Build stamp         | `setup.py` writes `adflow/gitInfo.py` at `pip install` time; the root process prints `ADflow <version> / git <hash> (<branch>) / installed <time>` at start-up, with `*** DIRTY WORKING TREE ***` if there were uncommitted changes. The stamp identifies the last install, not the library: after a rebuild without a reinstall it is stale. A log without the line comes from a package that was not installed through `pip`.                                                                                    |
| Stale installs      | Scripts and tests import the installed package. Remove `build/` before `pip install`, otherwise an old Python layer can be packaged with a new stamp.                                                                                                                                                                                                                                                                                                                                                              |
| Python version      | `setup.py` states `python_requires=">=3.11"`, the same as upstream. The dependency bounds are relaxed (Section 6) so that older environments resolve, but the file does not declare support for Python 3.10; whether 3.10 works was not checked for this page.                                                                                                                                                                                                                                                     |
