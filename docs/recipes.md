# Validated solver recipes

Which solver settings converged which case, to what level, and what happens without them.
The option dictionaries themselves are in `examples/transition/recipes.py` (`RECIPES[...]`, one comment
per recipe naming the run that proved it); this page uses the same recipe names and does not repeat every
key. Numbers come from `showcase/_manifest_2d.md` and `showcase/_manifest_3d.md`.

Stages: ANK (segregated turbulence, DADI) → CANK below `ANKCoupledSwitchTol` → CSANK below
`ANKSecondOrdSwitchTol` → NK below `NKSwitchTol`. Levels are relative to the free-stream residual.
The standing target is `L2Convergence=1e-8`.

## 2. Dissipation

| Scheme (key in `recipes.DISSIPATION`) | Values                                                                                                   | Used for                                                 | What goes wrong otherwise                                                                                                                                                                                                |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `scalar`                              | scalar JST, `vis2` 0.25, `vis4` 0.01, `acousticScaleFactor` 1.0                                          | 2D runs of campaign `24_minmodel_2d`                     | `acousticScaleFactor` = Mach: about 3× more cycles and GR limit cycles on S809. `vis4` halved again: limit cycle.                                                                                                        |
| `matrix`                              | matrix dissipation, `vis4` 0.04, `epsShear` 0.0, `epsAcoustic` 0.25 (the coefficients of the P&Z solver) | paper comparison, every crossflow case                   | With `epsShear` at its default 0.025: flat plate lands on an early-transition branch (x_tr 0.50–0.57 instead of about 1.0); SA-BCM gives about twice the transitional drag. `epsShear` is the limiter of the convective eigenvalue; inside a boundary layer it sets the dissipation
of the shear wave, which is why the transition location responds to it.

## 4. Optimisation

| Setting                       | Value                                                                                              | Reason / what goes wrong otherwise                                                                                                                                      |
| ----------------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `L2Convergence`               | 1e-8 (2D)                                                                                          | At 5e-8 cd repeats only to about 7e-7 and SLSQP wandered in noise from iteration 100 to 155 (`08_optimization`, job 1801548).                                           |
| `adjointL2Convergence`        | 1e-9 scalar, 1e-8 matrix (2D); 1e-3 on the 3D attempt                                              | The 3D value was read from an adjoint-history study on that mesh; it is not a general recommendation.                                                                   |
| Adjoint solver, GR            | field split + LGMRES, subspace 400, `ILUFill` 3, `ASMOverlap` 3 (the pyADflow defaults)            | Additive Schwarz is 29 % slower in 2D and 5.0–5.7× slower on a 1.48 M-cell wing. Field split stagnates with a subspace of 200 or less and needs about 50 % more memory. |
| Adjoint solver, SA-γ          | additive Schwarz + GMRES, `outerPreconIts` 3                                                       | Field split needed 7–10× the GR iteration count for this model. With 3 instead of 10 outer iterations the cd adjoint went from 457 s to 209 s.                          |
| Adjoint solver, SA-BCM and SA | additive Schwarz + GMRES, subspace 400, `ILUFill` 3, `ASMOverlap` 3                                | Field split does not help without transported transition variables.                                                                                                     |

## 5. Reading a run that does not converge

| Symptom                                                                           | Likely cause and action                                                                                                                                                                     |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CFL equal to `ANKCFLLimit`, step 1.00, healthy linear residual, no progress       | The ceiling is saturated. Raise `ANKCFLLimit` (1e8). Tightening the linear tolerance does not help.                                                                                         |
| NK at step 0.00, residual creeping in the 12th digit                              | NK engaged too early. Restart with `useNKSolver=False`; on the AR5 wing this closed the last order in 2–27 iterations. Do not restart NK at the same threshold.                             |
| Residual flat near 1–2e-5 on a shape with a laminar bubble (GR, matrix)           | Start the second-order stage earlier: `ANKSecondOrdSwitchTol=1e-4`.                                                                                                                         |
| Drag cycling, or a floor at 7–8 orders, on a laminar bubble at low Mach and Tu    | `ANKTransitionGlobalLambda=False`, `ANKStallSwitchIters=40`, `ANKStallSwitchCharOff=True`, `turbL2Convergence=1e-8`, `ANKLinResMax=0.9`. NACA 0012, M 0.089, Tu 0.03 %, Re 2e5–1e6, α 2.7–6°, GR, matrix: 7 of 7 converged. `ANKCharPresCutoff=1` is a passive alternative (6 of 7). |
| Flat plateau for hours on a crossflow case, step 1.00, linear residual about 0.05 | Possibly the crossflow front still settling. The sickle wing sat at 4.8 orders for about 15 h and then dropped 20× in 80 iterations. Check whether γ and R̅eθt still change before stopping. |
| Limit cycle near 1e-5, a few cells with γ at its lower bound                      | Seen on S809 α 7° with matrix dissipation before the coupled-ANK bound fix (commit 8d0943e9, included). If it persists the flow may have no steady solution (low Tu, laminar bubble).       |
| Step limited to 0.01–0.03 throughout coupled ANK                                  | γ at the transition front limits the global step. Try `ANKTransitionGlobalLambda=False`, with `ANKCFLMinCap` (sickle recipe).                                                               |
| CSANK oscillates after reaching about 3.5e-8 on a large 3D mesh                   | A small front adjustment kicks the residual. Hand over earlier or accept the level.                                                                                                         |
| Out of memory in CANK on a large mesh                                             | Memory is set by the preconditioner fill, not by the Krylov subspace: 7.42 M cells need about 3 GB per rank with ILU(1) and do not fit one 242 GB node with ILU(2). Add nodes.              |

Memory guide for GR on 64 ranks: 3.67 M cells about 105 GB with NK; 4.4 M cells about 100 GB without NK
(estimate from the job script, not measured); 7.42 M cells need two nodes.

## 6. Relation to the solver of the paper

| Aspect           | Piotrowski and Zingg (Newton–Krylov–Schur)                    | This code                                                                                                                                          |
| ---------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Globalisation    | fully coupled approximate Newton from the first iteration     | segregated ANK, then coupled ANK at `ANKCoupledSwitchTol`                                                                                          |
| Final phase      | inexact Newton                                                | CSANK (second-order Jacobian with a pseudo-time term); NK is the limit of that with no time term                                                   |
| Preconditioner   | approximate Schur                                             | ILU / additive Schwarz, assembled by AD (`ANKADPC`, `NKADPC`)                                                                                      |
| Step control     | per-node damping of γ and R̅eθt (Algorithm 2) and backtracking | global step from the physicality check and line search; per-node damping in DADI and NK, and in coupled ANK with `ANKTransitionGlobalLambda=False` |
| Source stiffness | time-step restriction (Eq. 59), released after clean steps    | same (`transitionSrcDtRestrict`, `srcDtDeactivateIters`); additive on the diagonal in DADI, maximum form in the Krylov paths                       |
| Scaling          | row and column scaling (Eq. 58)                               | `turbResScale` rows and matching column scaling of the Krylov systems                                                                              |

Iteration counts are therefore not comparable one to one with the paper; compare wall time.
On the 2D validation cases the runs took 287–1813 s (NLF(1)-0416) and 354–956 s (S809) on 7–32 ranks
(campaign `12_paper_conditions`).

## 8. Running on a cluster

`examples/transition/job_template.sh` is the Slurm template (one node, one `srun` per case, each with its
own `timeout`). Points that matter for these models: one MPI rank per core and `OMP_NUM_THREADS=1`;
ADflow traps SIGUSR2, writes the solution and leaves the solve, so stop a job with
`scancel --signal=USR2 <jobid>` to keep the flow state; never set `writeSolutionEachIter=True`;
keep the ADflow banner line of each log (it identifies the build).
