# Tried and rejected

Ideas, options and settings that were tested during development and are not part of this code or of the
recommended practice, with what happened and where the evidence is. The purpose is to save the next person
from repeating them.

How to read the table:

- **Evidence** names the campaign (folder name used in `showcase/_manifest_2d.md` and
  `showcase/_manifest_3d.md`); job numbers are provenance only. "Development log" means the commit messages
  of the development branch, which recorded the test that motivated or rejected an option.
- **Verdict**: *removed* = option deleted from the code (passing it raises the pyADflow "option not valid"
  error); *constant* = option deleted, value fixed in the code; *kept* = still in the code;
  *do not use* = a setting of an existing option that failed; *success* = listed because it closes a
  line of failed attempts.
- Section A covers all 36 options removed from the development branch. Sections B–F are dead ends that
  never were options, or settings of existing options.
- All tests were run with development builds. Nothing here was repeated on the cleaned branch.
